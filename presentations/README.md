# 演讲稿 / Presentation Slides

本目录包含配套的 HTML 演讲稿，用于技术分享现场。

## 使用方式

直接用浏览器打开即可：

```bash
open how-to-build-an-agent/index.html
```

使用左右方向键翻页。

## 内容

- **how-to-build-an-agent/** — "如何构建一个 Agent" 技术分享，内容包括：
  - Agent 四大功能模块介绍
  - ReAct 论文背景和意义
  - ReAct 模式详解
  - 动手实现的核心代码
  - Live Demo（嵌入本项目的 Web UI）
